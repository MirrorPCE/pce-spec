# PCE 接口规格（中文说明）

> 副题：一个PCE需要操作系统提供什么

> RFC v0.1 草案 · 欢迎提issue讨论 · Mirror Project · mirrorpce.com

## PCE是什么

**PCE——个人认知外骨骼（Personal Cognitive Exoskeleton）**：一个替你做事的AI，
你的数据留在你自己的手机里，它对你的东西做过什么，你都看得到。

**站位**：我们不是操作系统，也不是又一个Agent平台。PCE不与OS争位、
不与Agent争位、不与云争位——它只站在用户身边。它与你已经在用的工具并肩工作。
**强化一切，取代无物。** 判据只有一条：主权和记忆归用户。

## 六判据

①用户拥有 ②能在手机上跑 ③记得你说过的话 ④看得见的隐私 ⑤跨生态中立
⑥**跑在你已有的硬件上**——Android 12 或更新，你已有的手机。

## 形态

Android手机。
