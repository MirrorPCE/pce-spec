# PCE 接口规格（中文说明）

> 副题：一个PCE需要操作系统提供什么

> RFC v0.1 草案 · 欢迎提issue讨论 · JadeAurum · Mirror Project · mirrorpce.com

## PCE是什么

**PCE——个人认知外骨骼（Personal Cognitive Exoskeleton）**：一个属于你的AI。
它在本地思考、长期记得你、隐私由架构保证而非承诺保证、跨生态中立、
跑在你已经拥有的硬件上。

**站位**：我们不是操作系统，也不是又一个Agent平台。PCE不与OS争位、
不与Agent争位、不与云争位——它只站在用户身边。你想用什么，它就替你去用。
**强化一切，取代无物。** 判据只有一条：主权和记忆归用户。

## 六判据

①用户拥有 ②本地思考 ③长期记忆 ④架构级隐私 ⑤跨生态中立
⑥**跑在你已有的硬件上**——不需要为AI换一台新手机。

## 两种合法形态

- **全体形态**：脑与窗口同在一台你的设备（Android手机）。
- **窗口形态**：脑在你自有的另一台设备上（退役PC复活当脑），
  手机/iPhone当窗口——数据全程在你自己的硬件里，判据不破。
