# PCE Interface Specification

> *What a PCE needs from the operating system*

> **RFC v0.1 (draft)** — Request for Comments. Issues welcome.
> Mirror Project · [mirrorpce.com](https://mirrorpce.com)

## What is a PCE?

**PCE — Personal Cognitive Exoskeleton**: an AI that works for you, with your
data kept on your own phone, and you can see what it did with your things.

**Positioning**: We are not an OS. We are not another agent platform.
A PCE does not compete with the OS, with agents, or with the cloud —
it stands beside the user. It works alongside the tools you already use.
**Strengthen everything, replace nothing.**
The only test: *sovereignty and memory belong to the user.*

## The Six Criteria

A system qualifies as a PCE only if it meets all six:

| # | Criterion | Meaning |
|---|-----------|---------|
| 1 | User-owned | The agent is yours; it exists without any vendor account |
| 2 | Thinks locally | Can run a small model on your own phone; a cloud model only if you add your own key |
| 3 | Long-term memory | It remembers what you told it, in your own words |
| 4 | Architecture-level privacy | Privacy you can check: nothing leaves until you open the door; each door can be closed |
| 5 | Cross-ecosystem neutral | Not locked to any vendor's ecosystem |
| 6 | Runs on hardware you already own | Android 12 or newer, a phone you already own |
