# Contributing

Thanks for your interest in the PCE specification.

## How to comment (no CLA needed)
Open an issue titled `[RFC] §<section> <topic>`. Plain-language
arguments are welcome — this spec is meant to be readable by anyone.

## How to contribute text (CLA required)
Pull requests that change spec text require signing our Contributor
License Agreement (CLA) so contributions can be distributed under the
project's licenses. The CLA bot will prompt you on your first PR.

## Merge authority
Merge authority: Mirror Project.

## Ground rules
- Be specific: reference section numbers.
- Proposals must preserve the six criteria — issues that amount to
  "let the vendor cloud hold the memory" are out of scope by design.
